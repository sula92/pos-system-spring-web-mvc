# Hibernate ORM Migration - Quick Start Guide

## ✅ Migration Complete!

The `pos-system-spring-web-mvc` module has been successfully migrated from raw JDBC to **Hibernate ORM** with Spring Data JPA support.

---

## What Changed?

### ✨ Key Improvements

| Aspect | JDBC (Before) | Hibernate (After) |
|--------|---------------|-------------------|
| **SQL Writing** | Manual SQL queries | Auto-generated by Hibernate |
| **Connection Management** | Manual try-catch-finally | Spring handles automatically |
| **DAO Code** | ~400 lines per DAO | ~15 lines (interface only) |
| **Transactions** | Manual begin/commit/rollback | `@Transactional` annotation |
| **Error Handling** | Manual exception handling | Spring exception translation |
| **Type Safety** | SQL string constants | Compile-time checked |

## Quick Start

### Prerequisites
```bash
✓ Java 17+
✓ Maven 3.8+
✓ PostgreSQL 12+ (default: localhost:5432)
✓ Tomcat 9+ (or embedded server)
```

### Step 1: Build
```bash
cd pos-system-spring-web-mvc
mvn clean package
```

### Step 2: Deploy
```bash

mvn tomcat7:run

# Option B: Standalone Tomcat
```

### Step 3: Test
```bash

  -H "Content-Type: application/json" \
  -d '{"customerId":"C001","orderDetails":[{"itemCode":"I001","qty":2,"unitPrice":120.00}]}'
```

## Architecture Changes

### JDBC Stack (Old)
```
Controller
  └─> Service (manual transaction management)
       └─> Repository (manual JDBC code)
            └─> Database.getConnection()
                 └─> Raw SQL execution
```

### Hibernate Stack (New)
```
Controller
  └─> @Service @Transactional (Spring manages transactions)
       └─> @Repository JpaRepository (interface only!)
            └─> Hibernate (auto SQL generation)
                 └─> EntityManager (manages entities)
                      └─> DataSource (connection pool)
```

```java
@Repository
public interface CustomerRepository extends JpaRepository<CustomerEntity, String> {
    // save(), findById(), findAll(), delete(), etc. all provided automatically!
```

### New Service with @Transactional
```java
@Service
@Transactional  // Spring automatically manages begin/commit/rollback
public class CustomerService {
    @Autowired
    private CustomerRepository repo;
    
    public CustomerDTO saveCustomer(CustomerDTO dto) {
        // No manual transaction code needed!
        CustomerEntity entity = new CustomerEntity(dto.getId(), dto.getName(), ...);
        return convertToDTO(repo.save(entity));  // Hibernate generates INSERT
    }
}
```

## Key Features

### 1️⃣ Automatic SQL Generation
```java
// Before: Manual SQL
PreparedStatement ps = conn.prepareStatement("INSERT INTO customers (id, name, address, email) VALUES (?, ?, ?, ?)");
ps.setString(1, entity.getId());
ps.setString(2, entity.getName());
// ...
ps.executeUpdate();

// After: Hibernate generates SQL automatically
repository.save(entity);  // That's it!
```

### 2️⃣ Automatic Transaction Management
```java
// Before: Manual transaction management
try {
    connection.setAutoCommit(false);
    // ... do work ...
    connection.commit();
} catch (Exception e) {
    connection.rollback();
    throw e;
}

// After: Spring handles it with @Transactional
@Transactional
public void placeOrder(OrderDTO dto) {
    // If ANY operation fails, entire transaction rolls back automatically!
    repo.save(...);
    repo.save(...);
}
```

### 3️⃣ Relationship Management
```java
// Automatic one-to-many relationship
@Entity
public class OrderEntity {
    @OneToMany(mappedBy = "order", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<OrderDetailEntity> orderDetails = new ArrayList<>();
}

// Load relationships automatically
OrderEntity order = orderRepository.findById("O001").get();
List<OrderDetailEntity> details = order.getOrderDetails();  // Auto-loaded!
```

### 4️⃣ ACID Transactions with Automatic Rollback

## Database Schema (Auto-Generated by Hibernate)

Hibernate automatically creates these tables:

```sql
CREATE TABLE customers (
    id VARCHAR(10) PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    address VARCHAR(255),
    email VARCHAR(150)
);

CREATE TABLE items (
    code VARCHAR(10) PRIMARY KEY,
    description VARCHAR(255) NOT NULL,
    unit_price NUMERIC(10,2) NOT NULL,
    qty_on_hand INTEGER NOT NULL
);

CREATE TABLE orders (
    order_id VARCHAR(10) PRIMARY KEY,
    date DATE NOT NULL,
    customer_id VARCHAR(10) NOT NULL,
    FOREIGN KEY (customer_id) REFERENCES customers(id)
);

CREATE TABLE order_details (
    order_id VARCHAR(10) NOT NULL,
    item_code VARCHAR(10) NOT NULL,
    qty INTEGER NOT NULL,
    unit_price NUMERIC(10,2) NOT NULL,
    PRIMARY KEY (order_id, item_code),
    FOREIGN KEY (order_id) REFERENCES orders(order_id),
    FOREIGN KEY (item_code) REFERENCES items(code)
);
```

## Troubleshooting

### ❌ "No qualifying bean of type EntityManagerFactory"
✅ **Solution**: Ensure `@EnableJpaRepositories` is in `WebMvcConfig`

### ❌ LazyInitializationException
✅ **Cause**: Accessing lazy-loaded data outside transaction
✅ **Solution**: Add `@Transactional(readOnly = true)` to your query methods

### ❌ "Unknown column in field list"
✅ **Cause**: `@Column` name doesn't match database column
✅ **Solution**: Verify column names in annotations match database schema

### ❌ Composite Key issues
✅ **Solution**: Use `@EmbeddedId` with `@Embeddable` class (like `OrderDetailId`)

## Performance Optimization Tips

### 1. Use Read-Only Transactions
```java
@Transactional(readOnly = true)  // Optimized for queries
public List<CustomerDTO> findAllCustomers() { ... }
```

### 2. Use Pagination for Large Datasets
```java
Page<Customer> page = repository.findAll(PageRequest.of(0, 10));  // 10 per page
```

### 3. Create Custom Named Queries
```java
@Query("SELECT c FROM CustomerEntity c WHERE c.name LIKE %:name%")
List<CustomerEntity> findByNameContaining(@Param("name") String name);
```

### 4. Enable Second-Level Caching
```properties
spring.jpa.properties.hibernate.cache.use_second_level_cache=true
```
